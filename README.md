# 📸 Lens Photographie

Site vitrine pour photographe développé lors de mon apprentissage du développement web.

## 📋 À propos

Premier projet de site web statique créé lors de mon apprentissage du HTML et CSS. Le site présente le portfolio d'un photographe fictif spécialisé dans les paysages et portraits.

## ✨ Fonctionnalités

- Page d'accueil avec présentation du photographe
- Portfolio avec galeries photo (paysages et portraits)
- Effet hover sur les images
- Formulaire de contact
- Page "À propos" avec services et tarifs
- Design responsive (mobile, tablette, desktop)

## 🛠️ Technologies utilisées

- **HTML5** - Structure des pages
- **CSS3** - Styles et mise en page
  - Flexbox
  - CSS Grid
  - Media queries pour le responsive

- Mobile : passage en colonne unique
